## 🚀 CDN Usage

You can use these translations directly via CDN without cloning the repository.

### 1. jsDelivr (Recommended)
Use jsDelivr for fast and reliable distribution.

**Pattern:**
`https://cdn.jsdelivr.net/gh/zaibihsn/translation-all@v1.0/[id].zip`

**Example:**
[https://cdn.jsdelivr.net/gh/zaibihsn/translation-all@v1.0/english-saheeh-international.zip](https://cdn.jsdelivr.net/gh/zaibihsn/translation-all@v1.0/english-saheeh-international.zip)

### 2. Raw GitHub
Use Raw GitHub for direct access to the files.

**Pattern:**
`https://raw.githubusercontent.com/zaibihsn/translation-all/main/[id].zip`

**Example:**
[https://raw.githubusercontent.com/zaibihsn/translation-all/main/english-saheeh-international.zip](https://raw.githubusercontent.com/zaibihsn/translation-all/main/english-saheeh-international.zip)
